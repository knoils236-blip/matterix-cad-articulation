# 从配合推导运动学（build_rig.py / mate_dof.py）

## 算法

1. **线性化**：每个零件当作一个刚体，有 6 个旋量分量 (v, ω)，v 取在世界原点。每条配合在保存位姿处线性化为若干行约束。
   - 重合（平面–平面）：1 行平移 + 2 行转动；
   - 同心：2 行平移 + 2 行转动；
   - 宽度：两侧中面重合；
   - 对称：耦合行；
   - 平行：只约束转动；
   - 限位距离配合只限制范围，不提供平移约束行；
   - MateSlot 跳过。
   
   `mate_dof.py` 单独运行时，会按子装配是否柔性合并刚体，并输出各运动组的自由度，适合粗看整机。
2. **零空间**：约束矩阵 J 的零空间 N，就是配合允许的全部运动。`RANK_TOL=1e-7`（相对值）；阈值再大，CAD 里近似冗余的配合会被误判为锁死。
3. **关节坐标**：零件之间、带行程的限位距离配合，以平面法向的距离变化率作为关节坐标。速率在 N 上平行的限位描述的是同一个关节（例如龙门两侧的两个 Y 模组），合并为一组，行程取交集。
4. **停放配合放开**：如果某个限位在 N 上的速率为 0（被锁住），就找出锁住它的配合行。其中属于“停放”类的被逐行丢掉，迭代最多 6 轮。停放类包括：距离配合、指向子装配自身基准面的配合。丢掉的行记在 `droppedParkingRows`。
5. **最平滑运动**：对关节 k，在 N 内最小化按配合数加权的相邻体相对旋量（拉普拉斯），约束条件是 q_k' = 1、其他关节 q' = 0、父侧刚体旋量 = 0，用 KKT 求解（lstsq）。父侧这样确定：限位两侧如果恰有一侧零件名以 `stator_prefixes` 开头（默认 `主体`），它就是父侧；否则取较慢的一侧。
6. **link 划分**：每个零件对每个关节有一个 0/1 签名，表示是否沿子侧方向移动超过 50%。签名相同的零件归为同一个 link。子 link 的签名去掉第 k 位后，必须等于父 link 的签名，否则记为 problem。

## 读 show_rig 输出、修问题

| 现象 | 常见根因 | 处理 |
|---|---|---|
| `ORPHAN`，父 link 是 `?` | 某个零件的签名掺进了不该有的位：父子方向判反，或运动从别处漏了进来 | 用 `--body` 查关键零件随哪些关节动；检查直线模组主体名是否被 `stator_prefixes` 识别；拓扑不清的地方写 `weld` |
| 运动件随某个关节动、却不随它的上级关节动 | 有配合把它连到整机原点基准面或地上（停放） | 在 export 里找该组零件与组外零件之间的配合（组外签名为全 0 或为 own），确认是停放性质后写进 `drop` |
| 限位被锁（`lockedLimitMates`） | 非停放配合锁死；也可能 CAD 本来就是锁定状态 | 如果确实应该能动，找出锁死它的配合：属于停放性质就 `drop`，否则问用户 |
| `unjointed_*` 有零件 | 一组零件能动，却没有限位配合给它坐标 | 多数是装配时没约束全的紧固件，焊到相邻件上；如果确实是机构：直线的请用户补限位配合；旋转的按 manual-rig.md 手写关节 |
| 被动件成了独立关节（气弹簧、阻尼器、同步带另一侧） | 它的行程完全由另一个关节决定 | 按实机连接焊接两端（例如杆接机架、缸筒接门），让它的限位并入主关节，行程取交集 |
| 关节数多于预期，且大量相同 | 注射器推杆、手指等标准件的限位 | 保留；用 `names` 命名，`show_rig --hide` 隐藏 |

规则：每条 `weld` / `drop` 都要有可以复核的依据（说明书页码、型号手册、坐标重合加用户确认）。几何推断要先列成拓扑表请用户确认，再写入。启发式改动（例如改停放规则）会让别处回归：移液站上改过三次，每次都修好一处、弄坏另一处。显式事实比继续调启发式稳定。

## 能力边界

- 配合推导只生成 **移动关节**：关节坐标来自限位距离配合。限位角度配合还没实现，旋转关节（铰链门、转台、旋转电爪）按 [manual-rig.md](manual-rig.md) 的字段手写进 `rig.json`，`build_articulated.py` 会照建。
- 对称或齿轮耦合的夹爪只有一个手指成为关节，另一指固定在夹爪体上。如果需要 mimic，要另外做。
- 运行时间约 3 min（1040 体、6240 列的稠密 SVD，每轮放开都要重算）；内存约数 GB。
